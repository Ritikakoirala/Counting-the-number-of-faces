# 👤 Counting the Number of Faces (Real-Time)

A real-time face detection and counting system using **Python**, **OpenCV**, and **dlib**.  
The application captures live video from a webcam, detects human faces, draws bounding boxes, and displays the total number of faces detected in each frame.

---

## 📌 Features

- 🎥 Real-time webcam video capture  
- 🙂 Automatic frontal face detection  
- 🔢 Counts multiple faces simultaneously  
- 🟩 Draws bounding boxes around detected faces  
- 🏷️ Labels each detected face with a unique number  
- ⌨️ Press **`q`** to exit safely  
## 🛠️ Technologies Used

- **Python 3.10 / 3.11**
- **OpenCV (cv2)**
- **dlib**
- **NumPy**
